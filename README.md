# 🎰 Maya Bingo

A stylish, group-friendly bingo game bot for Telegram with automatic calling, beautiful graphics, and interactive card selection.

## 📋 Features

- **Group Play** — Play bingo with multiple players simultaneously in Telegram groups
- **Beautiful UI** — Best-in-class graphics and modern stylish design optimized for Telegram
- **Automatic Calling System** — Automated number calling with smooth animations
- **Card Selection** — Users can choose and customize their bingo cards
- **Interactive Gameplay** — Real-time updates and engaging user experience
- **Telegram Bot Integration** — Seamless integration directly in Telegram chats

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Telegram Bot API token

### Installation

```bash
git clone https://github.com/Test994101/maya-bingo1.git
cd maya-bingo1
pip install -r requirements.txt
```

### Configuration

1. Create a Telegram bot using [@BotFather](https://t.me/botfather)
2. Add your bot token to the configuration
3. Start the bot with your bot token

```bash
python main.py --token YOUR_BOT_TOKEN
```

## 🎮 How to Play

1. Add the bot to your Telegram group
2. Start a new game with `/bingo` command
3. Each player selects their bingo card
4. The bot automatically calls numbers
5. First player to mark all numbers wins!
